# BaiMai Wholesale Thailand Website

Open `index.html` in a browser to review the public partner-acquisition website.

## Purpose

This site positions BaiMai Wholesale as a Thailand-wide B2B partner network for functional beverages, wellness products and selected consumer brands.

It is public-facing and focused on partner acquisition, selected brands and wholesale inquiries.

## Edit the business details

Most day-to-day edits are in `wholesale-data.js`:

- WhatsApp number
- Hero headline and subheadline
- Featured brands
- Brand products
- Who We Supply cards
- How It Works steps
- Partner benefits
- Future scalability items

The hero photo is stored at `assets/shop-no-banner.jpg`. Replace that file with another image using the same filename if you want a different first-screen photo.

## Add more brands later

Add another object to the `featuredBrands` list in `wholesale-data.js`. Each brand can have its own product list, description and status label.

Red Hippo is the first featured brand, with BaiPure as the first focus product.
